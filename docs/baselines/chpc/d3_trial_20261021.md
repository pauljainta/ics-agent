# D3 CHPC offline trial, 2026-10-21

This is an engineering smoke trial of the full official
[`vllm-sr/d3`](https://huggingface.co/vllm-sr/d3) checkpoint, revision
`cf15549a78fc52598ddd1951f321c58372bbd64f`. It is distinct from the
local oMLX quantization, Qwen results, any 50-pair measured study, official
CTF scoring, and physical PLC experiments.

## Deployment and admission

- CHPC jobs: environment `16410055` completed; data transfer `16410056`
  completed; H100/CUDA probe `16410145` completed; D3 server `16410180`
  ran on an H100 NVL node and was stopped after the trials. A duplicate guest job
  was cancelled. The pinned package was downloaded through the data transfer
  partition.
- Runtime: upstream `d3_server.py`, PyTorch `2.14.1+cu130`, Transformers
  `5.17.0`, CUDA runtime `13.0`, NVIDIA driver `580.178.04`, H100 NVL with
  `95,830 MiB` reported by `nvidia-smi`. The server used the reference PyTorch
  kernels; optional fast kernels were absent.
- The D3 server bound compute loopback only. The compute relay admitted only
  the current CHPC login IP and required a bearer key for health, model list,
  and System One requests. An unauthenticated health probe returned 401;
  authenticated `/health` and `/v1/models` returned 200 with model `d3`.
  The relay logged **370 successful System One POSTs**: two PLCBench preflight,
  eight CTF1 smoke, and 360 full WT fixture decisions.
- The job identity file contains the checkpoint revision, model manifest,
  config and server hashes, pip freeze hash, job script and relay hashes, GPU,
  driver, node, and job ID. The local script, relay, and pip freeze bytes match
  those hashes. Both result bundles embed this identity snapshot. The HTTP
  endpoint does not attest its own weight revision; the bundles label this
  `provided_unverified_endpoint_binding`.

## PLCBench water treatment fixture

The two fixed cases used the same source-derived offline fixture as the
reference and deterministic policies: fixture SHA-256
`1f51ba2e6a64a202cf3da591ca7b495c5747694f44c1c46e8dac168918a34c55`.
The source identity, observation fields, action authority, and 180-step case
length matched. Event hashes and identity snapshots were rechecked from the
saved bundles. All three policies passed the fixture's safety and service
gates; the continuous scores are shown separately.

| Case | Policy | Safety score | Service score | Final experimental membrane damage |
| --- | --- | ---: | ---: | ---: |
| High pH | Reference | 1.00 | 1.00 | 0.00050707 |
| High pH | Deterministic | 1.00 | 1.00 | 0.00050707 |
| High pH | D3 | 1.00 | 1.00 | 0.00050707 |
| Low ORP | Reference | 1.00 | 1.00 | 0.00054877 |
| Low ORP | Deterministic | 1.00 | 1.00 | 0.00062992 |
| Low ORP | D3 | 1.00 | 0.95 | 0.00060135 |

D3 completed 180 decisions in each case. The saved events verify an
observation → decision → intervention → plant-response chain at the fixture's
equal authority. These are single fixed offline cases, so they do not
establish a performance difference. The membrane equation is experimental and
has no physical validation claim.

## CTF1 ICS staff smoke

The eight authored role-view cases produced **8/8** correct `if_policy_bearing`
binary labels at the fixture's 0.5 threshold. Mean Brier score was `0.0166`;
the deliberately trivial `starts with should` baseline was **5/8**. All eight
System One responses passed the adapter's role-action authority check. The
role actions do not have an independent action-quality gold label in this
fixture. The official CTF score and submission path were untouched.
