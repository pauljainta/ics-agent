# testbeds/water_distribution/openplc/scenarios

OpenPLC-level distribution runtime scenarios.

## Files

- [`idle.yaml`](idle.yaml): idle process setup.
- [`nominal_startup.yaml`](nominal_startup.yaml): nominal startup setup.
- [`high_demand.yaml`](high_demand.yaml): high-demand process setup.
- [`alarm_hh.yaml`](alarm_hh.yaml): high-high alarm setup.

These are lower-level runtime scenarios, distinct from wargaming scenarios in [`../../scenarios/`](../../scenarios/README.md).
