# testbeds/water_distribution/openplc/scripts

Distribution OpenPLC helper scripts.

## Files

- [`modbus_bridge.py`](modbus_bridge.py): source-backed controller/simulator Modbus bridge for the distribution testbed.
- [`validation_harness.py`](validation_harness.py): helper for validating OpenPLC invariants and process behavior.
- [`requirements.txt`](requirements.txt): helper-script Python dependencies.

These scripts are runtime support for the distribution backend and are not top-level experiment entry points. Use [`../../../../scripts/`](../../../../scripts/README.md) for experiment execution.
