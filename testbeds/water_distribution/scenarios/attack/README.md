# testbeds/water_distribution/scenarios/attack

Water-distribution attack scenarios.

## Files

- [`wd_supply_low_spoof.yaml`](wd_supply_low_spoof.yaml): supply-tank low-level telemetry spoofing.
- [`wd_supply_high_high_spoof.yaml`](wd_supply_high_high_spoof.yaml): supply-tank high-high telemetry spoofing.
- [`wd_grid_low_spoof.yaml`](wd_grid_low_spoof.yaml): distribution-grid low-level spoofing.
- [`wd_grid_high_spoof.yaml`](wd_grid_high_spoof.yaml): distribution-grid high-level spoofing.
- [`wd_grid_oscillation_spoof.yaml`](wd_grid_oscillation_spoof.yaml): oscillating grid-level spoofing.
- [`wd_grid_valve_force_open.yaml`](wd_grid_valve_force_open.yaml): forced grid-valve actuation.
- [`wd_rws_high_spoof.yaml`](wd_rws_high_spoof.yaml): return-water high-level spoofing.
- [`wd_rws_low_spoof.yaml`](wd_rws_low_spoof.yaml): return-water low-level spoofing.
- [`wd_rws_pump_force_open.yaml`](wd_rws_pump_force_open.yaml): forced return-water pump activation.
- [`wd_coordinated_supply_grid.yaml`](wd_coordinated_supply_grid.yaml): coordinated supply/grid manipulation.
- [`wd_coordinated_grid_rws_delay.yaml`](wd_coordinated_grid_rws_delay.yaml): delayed-impact grid/return-water manipulation.

These scenarios are used by distribution seeded, ablation, and baseline runs.
