Distribution-specific knowledge files loaded by agent profiles.

- [`attacker_manual.md`](attacker_manual.md): attacker-facing distribution context.
- [`defender_manual.md`](defender_manual.md): defender-facing distribution context.

- [`white_box_no_safety_bounds_attacker_manual.md`](white_box_no_safety_bounds_attacker_manual.md): white-box ablation manual with safety bounds withheld.
- [`white_box_no_control_semantics_attacker_manual.md`](white_box_no_control_semantics_attacker_manual.md): white-box ablation manual with control semantics withheld.
- [`phase35/`](phase35/README.md): target-blind domain/cyber primer output.

Knowledge files should describe permitted profile context only. They should not include hidden evaluator labels, authored mitigations, private infrastructure, or secrets.
