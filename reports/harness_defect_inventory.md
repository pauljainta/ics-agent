# Harness Defect Inventory

Date: 2026-11-16
Branch: `scadaver`

This inventory covers engineering defects in the frozen OpenPLC E1-E5 harness. It does not reinterpret historical model outcomes or change prompts, objectives, evaluator criteria, action permissions, PLC logic, or historical artifacts.

| Issue | Previous evidence | Classification and root cause | Repair | Verification | Status / residual risk |
|---|---|---|---|---|---|
| H1 HTTP inspection | OpenPLC HTTP fingerprint calls timed out or returned an opaque `redirect_limit_reached`. | Confirmed harness defect. Port 8080 was sent through the Modbus-oriented generic scanner, and root redirects lacked useful bounded metadata. | Port 8080 now performs a bounded HTTP `HEAD`; root inspection reports redirects without following; resource inspection follows only bounded same-host HTTP redirects and distinguishes loops, limits, missing locations, unsupported schemes, and cross-host rejection. | HTTP fixture coverage includes 200, 301/302/307/308, relative/absolute redirect, loop, limit, cross-host, unsupported destination, timeout, OpenPLC-like and generic industrial pages. Deployed `.10:8080` returned HTTP 302 and `/login` without claiming identity. | RESOLVED. Product identity still requires model-selected resource inspection; the harness does not select `/login` for the agent. |
| H2 state freshness | Agent-visible inlet state could differ from the broker's later post-quiescence baseline. | Expected dynamic-system behavior plus an observability limitation, not an incorrect broker decision. Prior sample metadata was too coarse. | Time-series results now label sample index, collection Unix time, requested interval, sequential acquisition, and cross-device skew. Baseline records state that the process evolves continuously. Broker authoritative baseline remains private until after the action decision. | Temporal, switching, jitter, delayed/missing sample, and transaction tests pass. | DOCUMENTED / HARDENED. Read-only observations can become stale; no false freshness guarantee is made. |
| H3 input budget | Seed 101 ended at 2,033,978 input tokens against 2,000,000. | Confirmed admission defect. Request 84 was admitted with 26,332 remaining and consumed 33,250; request 85 was then admitted for finalization and consumed another 27,060. Accounting itself was not double-counted. | Conservative pre-request estimation reserves one finalization envelope. Provider usage remains authoritative. Retries and missing-usage attempts are counted, crossings are explicit, and subsequent requests fail closed. | Boundary, retry, missing usage, overrun, recovery, and no-action-during-finalization tests pass. | RESOLVED with documented limitation: exact provider billing cannot be guaranteed before response; conservative admission minimizes crossing and records any unavoidable crossing. |
| H4 tool failures | Seed 101 recorded 76 unsuccessful calls and 44 redundant probes. | Mixed. Opaque generic errors were a harness defect; repeated incompatible/redundant choices were agent behavior. | Versioned `scadaver-tool-result-v2` adds attempted/executed/retryable/budget/state-change/error-category metadata while preserving raw evidence and legacy error codes. No automatic corrective tool selection was added. | Deployed fault/security checks verify policy, range, rate-limit, incompatible OPC UA node, closed session, and disabled action failures. | RESOLVED at interface level. Agent may still choose poor or redundant probes, which remains a scientific outcome. |
| H5 stale deployment | Earlier B0 loaded mismatched `budgets.py` and `openrouter.py`. | Confirmed deployment defect. Partial file synchronization was not fail-closed. | Production manifest now covers transitive runner, worker, tool contract, acceptance, evaluator, prompt, config, and broker modules. Live inference requires a comprehensive acceptance artifact with matching manifest hash. | Access VM parity passed for files, imports, Python 3.10, and `pymodbus 3.6.9`. | RESOLVED. Any future source change requires an intentional manifest refresh and redeployment. |
| H6 E5 physical attribution | An older evaluator counted recovery-only level increase as objective achievement. | Confirmed historical evaluator defect already corrected before this task. | Retained causal evaluator `e5-causal-attribution-v3`; no historical scorecard was rewritten. | No-op, unapplied, genuine transition, wrong direction, recovery-only change, missing scan, timestamp, restoration, and health cases pass. | VERIFIED RESOLVED. |
| H7 initial comparability | Different continuously evolving process phases affected otherwise similar episodes. | Experimental-control limitation, not a runner failure. | Read-only baseline now records process sample, inlet, scan/flow fields when present, controller/service health, capture time, continuous phase, and that no reset occurred. | Operator baseline and initial-condition policy tests pass. | PARTIAL. Comparable future runs require a separately approved initial-state band; identical model seeds do not imply identical trajectories. |
| A1 acceptance action check | First hardening gate failed after completing mocks because it used obsolete `bounded_inlet_test` against a closed worker transport. | Confirmed acceptance-code defect. | Uses the public `bounded_binary_output` name and verifies rejection before transport dispatch. | Regression test proves disabled action never reaches a closed transport. | RESOLVED. |
| A2 acceptance schema check | Second gate treated model-selected endpoint fields as forbidden despite the frozen action schema intentionally exposing them. | Confirmed stale acceptance assertion. | Verifies the exact closed five-field schema and bounded duration; private broker allowlist remains authoritative. | Deployed fault/security suite and broker fixture tests pass. | RESOLVED without changing the action interface. |

## Intentionally unchanged

- Qwen model, prompts, objective, B0-B4 reasoning scaffolds, action catalog ordering, and evaluator criteria.
- One action request per episode; rejected requests consume the allowance; no automatic replay.
- Fixed private simulator allowlist, duration bound, emergency stop, restoration, and controller recovery.
- OpenPLC program, simulator physics, industrial services, network isolation, and SPHERE realization.
- All historical B0-B4 and multiseed result artifacts.
