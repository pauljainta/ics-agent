# configs/knowledge

This directory holds shared knowledge material that is not specific to one testbed.

## Contents

- [`shared/`](shared/README.md): target-blind attacker constraints and general ICS cyber methodology manuals.

Testbed-specific manuals live under:

- [`../../testbeds/water_treatment/knowledge/`](../../testbeds/water_treatment/knowledge/README.md)
- [`../../testbeds/water_distribution/knowledge/`](../../testbeds/water_distribution/knowledge/README.md)

## Purpose

Shared knowledge lets profiles express expertise that should remain independent of a specific plant instance. For example, a target-blind high-cyber attacker can receive general ICS methodology without receiving exact target-system tags or topology.
